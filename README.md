This repository contains my SQL practice queries, assignments, and database exercises created while learning and improving my SQL and database management skills.

This repository includes SQL programs and practice problems covering database fundamentals, queries, functions, joins, subqueries, operators, and data manipulation operations.

The purpose of this repository is to understand how databases work and improve query-writing skills required for backend development and software engineering roles.
